# 5. Resumen: Introducción a los agentes y al ecosistema de agentes de Google

Curso de cierre (10 min). Enlace: <https://www.skills.google/paths/3546/course_templates/1772>

## Conclusión

Repaso de la ruta:

1. **Conceptos básicos sobre los agentes** – acción y razonamiento autónomos para problemas complejos; arquitectura (modelo + herramientas + organización/memoria) que les permite planificar y cumplir objetivos; diferencia entre un agente y una API de LLM.
2. **Agentes empresariales y casos de uso** – cómo los agentes generan impacto medible (KPI) y cómo Gemini Enterprise permite crear y organizar los agentes adecuados, desde sin código hasta pro-code.
3. **Crea tu primera aplicación de Gemini Enterprise** (lab simulado) – conectar Drive, Calendar y Cloud Storage para tener un motor unificado de búsqueda y análisis, y usar Deep Research, generación de ideas multiagente y NotebookLM.

**Siguiente paso sugerido:** otras rutas de la serie **GEAR** (desarrollo, despliegue y escalamiento de agentes, p. ej. con ADK y Agent Platform).

!!! tip "Para recordar (toda la ruta)"
    - Agente = modelo (cerebro) + herramientas (manos) + organización (bucle percibir-pensar-actuar-verificar) + memoria/contexto.
    - Usar agentes solo cuando hay varios pasos, adaptación, razonamiento y acciones externas.
    - Ecosistema Google: Gemini Enterprise (usuarios/empleados), Agentes conversacionales y CX Agent Studio (clientes), ADK + Gemini Enterprise Agent Platform + Agent Runtime (desarrolladores), MCP para herramientas.

# AWS Entrena Bogotá · AWS Cloud Practitioner Essentials

Curso oficial de AWS Skill Builder en español (LATAM), unas 12 h 45 min, que se ofrece como ruta en **AWS Entrena Bogotá**. Cubre los fundamentos de la nube de AWS que pide la certificación **AWS Certified Cloud Practitioner**: servicios, infraestructura global, seguridad, precios, monitoreo, migración y buenas prácticas de arquitectura. Cada módulo termina con una evaluación que exige 80 %.

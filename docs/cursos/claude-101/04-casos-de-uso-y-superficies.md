## Otras superficies de Claude

| Herramienta | Ideal para | Dónde corre |
|-------------|------------|-------------|
| **Claude.ai** | Tareas generales, investigación, redacción, análisis, archivos | Web, escritorio y móvil |
| **Claude Code** | Desarrollo, navegar codebases, flujos con git | Terminal, IDE o navegador |
| **Claude Cowork** | Tareas complejas de varios pasos: briefs, documentos, organizar archivos, análisis | Escritorio (y web/móvil en ciertos planes) |
| **Claude Tag** | Colaboración en equipo, preparar reuniones, respuestas en contexto | Slack |
| **Claude Design** | Prototipos de UI, explorar variantes, mockups con el design system | Cualquier conversación y claude.ai/design |
| **Claude para Microsoft 365** | Editar en el documento abierto y llevar contexto entre apps | Barras laterales de Excel, PowerPoint, Word y Outlook (beta) |
| **Claude in Chrome** | Investigación web, correo, automatizar el navegador | Barra lateral de Chrome (planes pagos) |

**Claude Code:** describir la funcionalidad en lenguaje natural y que escriba código, corra pruebas y haga commits; depurar a partir de un error; entender un repo desconocido; automatizar tareas tediosas (lint, conflictos de merge, release notes).

**Claude Tag:** resumir hilos, redactar respuestas, preparar reuniones con conversaciones del workspace y pasar un bug o una discusión a una sesión de Claude Code etiquetando a Claude.

**Claude para Excel:** entender fórmulas entre hojas, cambiar supuestos preservando dependencias, rastrear `#REF!`, `#VALUE!` y referencias circulares, tablas dinámicas y gráficos.

**Claude para PowerPoint / Word / Outlook:** primer borrador desde notas en la plantilla del equipo, ajustar tono y estructura, trabajar comentarios y control de cambios, triage del correo y respuestas con contexto del calendario.

**Claude in Chrome:** resumir páginas, llenar formularios repetitivos, probar flujos de varios pasos y sacar contexto de herramientas internas sin API. Pide permiso antes de acciones de alto riesgo (compras, datos personales); bloquea por defecto sitios financieros y de contenido adulto; recomendado para tareas de bajo riesgo en sitios confiables.
